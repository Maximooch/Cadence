# Cadence Electron App - Improvement Roadmap

## Phase 1: Essential UX (Top 3)

### 1. Keyboard Shortcuts
- [x] `Cmd+N` - Add new task
- [x] `Cmd+Delete` - Delete selected task  
- [x] `Cmd+↑/↓` - Move task up/down
- [x] `Cmd+D` - Duplicate task
- [x] `Esc` - Close modals
- [x] `Cmd+1-7` - Jump to day (Monday-Sunday)
- [x] `Cmd+T` - Jump to Today

### 2. Task Completion
- [x] Checkbox to mark tasks done
- [x] Completed tasks grayed out/strikethrough
- [x] Progress bar showing % of day completed
- [x] "Clear completed" button
- [x] Completion stats in footer

### 3. Menu Bar Integration
- [x] Menu bar icon (tray) for quick access
- [x] Show current/next task in menu bar
- [x] Quick-add task from menu bar
- [x] Toggle window visibility from menu bar
- [x] Quit option in menu bar
