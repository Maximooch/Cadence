# Cadence Scheduler - Keyboard Shortcuts

## Global Shortcuts

| Shortcut | Action |
|----------|--------|
| `Cmd/Ctrl + N` | Add new task |
| `Cmd/Ctrl + T` | Jump to today |
| `Cmd/Ctrl + D` | Duplicate selected task |
| `Cmd/Ctrl + 1-7` | Jump to day (Mon-Sun) |
| `Esc` | Close modals / Cancel editing |

## Task Editing

| Key | Action |
|-----|--------|
| `↑ / ↓` | Move task up/down in list |
| `Delete` | Remove selected task |
| Click task name | Edit task |

## Day Selection

- **Click day button** in sidebar to switch days
- Each day has independent task list
- Changes auto-save to `schedule.yml`

---

*Note: `Cmd` on macOS, `Ctrl` on Windows/Linux*
